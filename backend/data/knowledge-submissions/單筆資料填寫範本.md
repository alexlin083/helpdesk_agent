# 單筆知識庫資料填寫範本

複製本檔並改檔名；所有「請填寫」均需替換。以下預選 IT 類別，自行改動時必須依 [提交指南](README.md) 同時調整 category 與 department。

## 主資料

```json
{
  "id": "請填寫唯一編號",
  "category": "IT_SUPPORT",
  "doc_name": "請填寫文件名稱",
  "section_title": "請填寫本段標題",
  "content": "請填寫資料狀態、適用條件、處理步驟、例外限制，以及人工處理條件。",
  "summary": "請填寫一至兩句摘要",
  "department": "IT資訊服務台",
  "version": "請填寫版本",
  "updated_at": "請填寫 YYYY-MM-DD",
  "source_url": null,
  "data_status": "PENDING_REVIEW"
}
```

## 驗證情境

以下範本預設可自動回答；若需轉派，改為 ESCALATE_TICKET，並將 expected_level、expected_department 改成固定選項中的正確值。

```json
{
  "message": "請填寫使用者的自然問法",
  "expected_intent": "IT_SUPPORT",
  "expected_action_route": "AUTO_REPLY",
  "expected_level": null,
  "expected_department": null,
  "expected_reply_points": [
    "請填寫必須回答的第一個重點",
    "請填寫必須回答的第二個重點"
  ]
}
```

其他問法：

- 請填寫相同需求的另一種問法。
- 請填寫相同需求的第三種問法。

## 來源與審核

| 項目 | 填寫內容 |
| --- | --- |
| 原始來源與章節 | 請填寫文件、章節或資料提供者；沒有正式來源時標示模擬 |
| 適用條件與版本依據 | 請填寫適用對象、系統／設備版本或模擬政策設定 |
| 人工轉派／優先等級依據 | 請填寫何時需人工、P1／P2／P3 的選擇理由；無工單填不適用 |
| 蒐集者 | 請填寫組員識別名稱，勿提供不必要的個資 |
| 審核狀態 | 待審核／需補資料／已審核 |
| 審核紀錄 | 請填寫核對日期與修正事項，未審核不要填已確認 |
